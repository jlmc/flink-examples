# Stateful Operators

## 1. Stateful & State

### What is a stateful application

Uma aplicação stateful mantém contexto entre eventos. Em vez de processar cada registo de forma isolada, o operador consulta e atualiza estado para produzir resultados corretos ao longo do tempo.

No domínio ADT, isto permite responder perguntas como:

- quantos eventos já chegaram por hospital;
- qual o último tipo de evento por facility;
- como evolui o fluxo de admissões/transferências/altas.

### State in Apache Flink

No Flink, o estado é gerido pelo runtime e pode ser:

- local ao operador, mas consistente com checkpoints;
- recuperável após falha;
- particionado por chave (keyed state) quando usamos `keyBy`.

Exemplo implementado: `stateful-and-state/StatefulAndStateAdtExample`.
